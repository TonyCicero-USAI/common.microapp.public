# common.microapp.public

A lightweight micro-app framework built with **Angular**. Intended to be used with a backend built on top of common.microservice.public.

### Prerequisites

- Node.js ≥ 18
- npm or yarn
- A microservice running common.microservice.public

### Installation

```bash
# Clone the repo
git clone <repo-url>
cd <repo>/common.microapp.public

# Install dependencies
npm install
# or
yarn install

# Clone the child repository
git clone <repo-url> app
cd app

# Install dependencies
npm install
# or
yarn install

```

```bash
# Development (auto‑reload)
```
